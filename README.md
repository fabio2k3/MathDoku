# MathDoku: Sistema Interactivo de Sudoku Matemático

## Descripción
MathDoku es un sistema innovador desarrollado en Haskell que reinventa el clásico juego de Sudoku mediante la integración de elementos matemáticos avanzados (paridad, divisibilidad, primalidad).

## Estructura del Proyecto
* **app/**: Ejecutable principal.
* **src/**: Librería con la lógica del núcleo (Core, Generator, Solver, Hints).
* **tests/**: Suites de pruebas.
* **docs/**: Documentación de arquitectura y diseño.
* **scripts/**: Scripts de utilidad para el desarrollo.

## Requisitos
* GHC (Glasgow Haskell Compiler)
* Cabal o Stack
